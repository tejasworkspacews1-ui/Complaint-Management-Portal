# Contributing

Thanks for contributing to Complaint Management Portal.

## Development
1. Install JDK 17+ and Maven 3.9+.
2. Clone the repository.
3. Run `mvn clean package`.
4. Run the generated JAR with `java -jar target/smart-complaint-portal-1.0.0.jar`.

## Pull Requests
Keep changes focused, preserve the MVC structure, avoid committing generated files, and include a short explanation of functional changes and testing performed.
